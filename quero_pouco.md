# Programação Web - 2026.2 - UFERSA Angicos

## Quero pouco (nota entre 4,0 e 5,0). Entregue tudo até 05/12/2026.

1 - Crie um repositório **privado** no formato `pweb_2026.2_primeironomeSegundonome`. Adicione a conta `pwebufersa` como colaborador e avise xico@ufersa.edu.br. O professor deve conseguir rodar tudo sem sua ajuda.

2 - Escolha uma entidade do mundo real (diferente de Pessoa) e crie um projeto Spring Boot com CRUD dessa entidade. Use Thymeleaf como template engine, banco H2 ou Postgres e Maven. O site precisa ter pelo menos 4 páginas dinâmicas com HTML, CSS e barra de navegação, pelo menos 3 páginas estáticas, formulário com pelo menos um campo validado em JavaScript, imagens e favicon.  O design (e o design-system) do site deve ser criado por você usando uma foto colorida de sua autoria como base visual (a foto original deve estar no repositório). O projeto deve rodar com `./mvnw spring-boot:run`.

3 - Hospede o projeto no Railway, Render ou outro serviço que rode Java/SpringBoot. Coloque o link no README.
