# Programação Web - 2026.2 - UFERSA Angicos

## Quero pouco (nota entre 4,0 e 5,0) — Entregue tudo até 05/12/2026.

1 - Crie um repositório **privado** no formato `pweb_2026.2_primeironomeSegundonome`. Adicione a conta `pwebufersa` como colaborador e avise xico@ufersa.edu.br. Organize o repositório para que outra pessoa consiga reproduzir o projeto.

2 - Escolha uma entidade do mundo real (diferente de Pessoa) e crie um projeto Spring Boot com CRUD completo dessa entidade. Use Thymeleaf como template engine, banco H2 em memória e Maven. O site deve ter pelo menos 4 páginas HTML e CSS com barra de navegação, formulário com pelo menos um campo validado em JavaScript, imagens e favicon. Deve conter também 3 páginas estáticas. O design (e o design system) do site deve ser criado por você usando uma foto colorida de sua autoria como base visual — a foto original deve estar no repositório. O projeto deve rodar com `./mvnw spring-boot:run` sem erros. Coloque o código no repositório do item 1.

3 - Hospede o projeto em algum lugar acessível por URL (Railway, Render ou outro serviço gratuito que suporte Java). Coloque o link no README do repositório.
