Componentes de Interface

1. Skeleton Loading

Representa visualmente o conteúdo enquanto os dados estão sendo carregados.

2. Modal

Janela sobreposta ao conteúdo principal.

3. Dialog

O elemento HTML <dialog> fornece uma implementação nativa de diálogo.

4. Tooltip

Pequena explicação exibida quando o usuário passa o mouse.

Esta é uma explicação contextual.

5. Dropdown

Menu com opções que aparece após uma interação.

6. Toast

Mensagem breve usada para informar o resultado de uma ação.

7. Snackbar

Mensagem temporária que pode oferecer uma operação adicional.

8. Drawer

Painel que desliza pela lateral da interface.

9. Sheet

Painel que desliza a partir da parte inferior.

10. Card

Componente para agrupar informações relacionadas.
